# Argument Model Ontology (AMO)

[![IRI](https://img.shields.io/badge/IRI-purl.org%2Fspar%2Famo-blue)](http://purl.org/spar/amo)

The **_Argument Model Ontology (AMO)_** is an OWL 2 DL ontology that aims to encode the Toulmin's theory through OWL classes and properties, in order to describe a web of inter-linked entities that participate, with a specific role, in one or more arguments.
